# Nexora Tech

Projeto acadêmico desenvolvido pelos alunos do 1º TDS da FIAP.

## Descrição
O Nexora Tech é uma iniciativa social que visa promover inclusão social através de tratamentos odontológicos gratuitos para pessoas em situação de vulnerabilidade. Este site foi desenvolvido utilizando apenas HTML e CSS.

## Funcionalidades
- Informações sobre o projeto
- Seção de perguntas frequentes
- Formulário de contato
- Informações dos integrantes do projeto
