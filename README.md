# NexoraTech

Projeto desenvolvido para a disciplina de Front-End, com foco em criar um site responsivo e funcional para apresentar a solução NexoraTech — um sistema + chatbot pensado para ajudar na organização de atendimentos da ONG Turma do Bem.

A proposta do trabalho é construir o front-end sem usar frameworks prontos (como Bootstrap), então tudo foi feito manualmente com HTML, CSS e JavaScript.

---

## O que o site tem

- Página inicial com resumo do projeto
- Página explicando a proposta, tecnologias e roadmap
- FAQ com perguntas frequentes (abre/fecha com JS)
- Página de contato
- Página com os integrantes do trabalho (com GitHub e LinkedIn)
- Menu fixo no topo com destaque da página atual
- Botão “voltar ao topo”
- Totalmente responsivo (funciona em celular, tablet e desktop)

---

## Tecnologias utilizadas

- HTML  
- CSS (responsividade com media queries e grid)  
- JavaScript (DOM, menu mobile, FAQ, scroll)  
- Lucide Icons (somente ícones, não é framework)  

> Obs: Nenhum framework de CSS foi usado (ex: Bootstrap, Tailwind, etc.).
